# Klaroh — Client visibility that stops silent churn

A high-fidelity landing page for Klaroh, built with React 19, Tailwind CSS v3.4.17, GSAP 3 (ScrollTrigger), and Lucide React.

## Stack

- **React 19** — latest stable
- **Tailwind CSS v3.4.17** — utility-first CSS
- **GSAP 3** — animations with ScrollTrigger plugin
- **Lucide React** — icon set

## Development

```bash
npm run dev    # start dev server
npm run build  # production build
npm run preview # preview production build
```
